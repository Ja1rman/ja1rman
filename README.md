## Selected Projects

### Digital asset arbitrage automation

My ITMO bachelor’s thesis and diploma project: a Go-based system for detecting and executing arbitrage opportunities across Bybit and MEXC.

- Real-time market data collection through WebSocket APIs
- Arbitrage opportunity detection across hundreds of trading pairs
- Automated order placement through exchange APIs
- Balance protection, logging, notifications, and real-market testing
- Concurrent processing optimized for low-latency decision-making

### Financial time-series forecasting by historical analogues

Current research project on similarity-based retrieval for financial time series.

- Retrieval of historically similar market patterns
- Adaptive forecasting based on nearest temporal analogues
- Evaluation of predictive value and retrieval strategies
- Research at the intersection of time-series analysis, information retrieval, and machine learning

### Network infrastructure automation

Production-oriented tools for automating infrastructure operations.

- Asynchronous configuration backup collection for approximately **4,000 network devices**
- Controlled concurrency, timeouts, SSH/Telnet fallback, and legacy-device support
- NetBox extensions for interface configuration templates, validation workflows, and configuration state management
- Automated documentation and operational workflows

### AI assistants and semantic search

Development of AI-powered services for searching, analyzing, and summarizing technical information.

- Semantic search with vector retrieval and reranking
- Retrieval-augmented generation and knowledge assistants
- Stateful AI-agent workflows built with **LangGraph**
- Integration of LLM-based services into production workflows
